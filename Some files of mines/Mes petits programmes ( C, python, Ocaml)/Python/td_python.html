Calculs, Opérations & Affectations
✦ Débutant § 7.1 · 7.2

Répondre aux questions suivantes sans exécuter le code, puis vérifier en Python :

  1. Quelle est la valeur de 7 // 2 ? Et de 7 % 2 ?
  2. Que vaut 2 ** 10 ?
  3. Écrire une instruction qui permute les valeurs de deux variables a = 5 et b = 3 en une seule ligne.
  4. Que vaut x après : x = 10 ; x += 3 ; x *= 2 ?
  5. Quelle différence entre 3/2 et 3//2 en Python 3 ?
# 1. 7 // 2 # → 3 (division entière) 7 % 2 # → 1 (reste / modulo) # 2. 2 ** 10 # → 1024 # 3. Permutation en une ligne (unpacking) a, b = b, a # 4. x = 10; x += 3 # x = 13 x *= 2 # x = 26 # 5. 3/2 → 1.5 (float), 3//2 → 1 (int)
💡 À retenir — Opérateurs Python ▾
  • // = division entière (quotient), % = modulo (reste), ** = puissance.
  • En Python 3, / retourne toujours un float, même entre deux entiers.
  • La permutation a, b = b, a utilise l'unpacking de tuple : c'est idiomatic Python.
  • Les opérateurs d'affectation augmentée (+=, *=, …) modifient la variable sur place.

Entrées & Sorties standards
✦ Débutant § 7.3

Écrire un programme Python qui :

  1. Demande à l'utilisateur son prénom et son âge.
  2. Calcule l'année de naissance (supposer que nous sommes en 2025).
  3. Affiche : «Bonjour [Prénom], vous êtes né(e) en [année].» via un f-string.
  4. Affiche l'âge sur 3 chiffres alignés à droite, et l'année sur 4 chiffres, en utilisant le formatage de print().
prenom = input("Votre prénom : ") age = int(input("Votre âge : ")) annee = 2025 - age print(f"Bonjour {prenom}, vous êtes né(e) en {annee}.") print(f"Âge : {age:>3}") print(f"Année: {annee:04d}")
💡 À retenir — input / print / f-strings ▾
  • input() retourne toujours une chaîne. Utiliser int() ou float() pour convertir.
  • Les f-strings (f"…{variable}…") permettent l'interpolation directe et le formatage : {val:>3}, {val:.2f}, etc.
  • Syntaxe de formatage : {valeur:alignement_largeur_type} — très attendue en évaluation.

Variables, Types & Conversions
✦ Débutant § 7.4 · 7.5

Pour chaque expression, donner le type et la valeur :

  1. type(3.0), type(3), type("3"), type(True)
  2. Que vaut True + True + False ?
  3. Que vaut bool(0) ? bool("") ? bool([]) ? bool(-1) ?
  4. Créer un nombre complexe z = 3 + 4j. Accéder à sa partie réelle et imaginaire. Calculer son module.

# 1. type(3.0) # float type(3) # int type("3") # str type(True) # bool # 2. True vaut 1, False vaut 0 → résultat = 2 True + True + False # → 2 # 3. Valeurs "falsy" bool(0) # False bool("") # False bool([]) # False bool(-1) # True (tout entier ≠ 0 est truthy) # 4. Nombres complexes z = 3 + 4j z.real # → 3.0 z.imag # → 4.0 abs(z) # → 5.0 (√(3²+4²)) # 5. None est retourné quand aucun return n'est explicite def f(): pass print(f()) # → None
💡 À retenir — Types Python ▾
  • Types immuables : int, float, complex, bool, str, tuple, bytes. Ils ne peuvent pas être modifiés après création.
  • bool est une sous-classe de int : True == 1, False == 0.
  • Valeurs falsy : 0, 0.0, "", [], {}, None. Tout le reste est truthy.
  • Une fonction sans return retourne implicitement None.

Soit s = "Bonjour le Monde!". Écrire les instructions Python pour :

  1. Afficher la longueur de s.
  2. Extraire "Monde" par slicing.
  3. Mettre toute la chaîne en majuscules, puis en minuscules.
  4. Remplacer "Monde" par "Python".
  5. Vérifier si la chaîne commence par "Bon".

s = "Bonjour le Monde!" len(s) # → 18 s[11:16] # → "Monde" s.upper() # → "BONJOUR LE MONDE!" s.lower() # → "bonjour le monde!" s.replace("Monde", "Python") # → "Bonjour le Python!" s.startswith("Bon") # → True s.split() # → ['Bonjour', 'le', 'Monde!'] s[::-1] # → "!ednoM el ruojnoB"
💡 À retenir — Chaînes & Slicing ▾

  • s[::-1] est le raccourci classique pour inverser une séquence.
  • Les chaînes sont immuables : les méthodes retournent une nouvelle chaîne.
  • Méthodes incontournables : len(), upper(), lower(), replace(), split(), strip(), startswith(), find().

Listes & Tuples
◆ Intermédiaire § 7.5.6 · 7.6.1

Soit notes = [14, 8, 17, 12, 9, 15]. Réaliser les opérations suivantes :

  1. Ajouter la note 11 en fin de liste.
  2. Insérer la note 10 en position 2.
  3. Supprimer la note 8 par sa valeur.
  4. Trier la liste dans l'ordre croissant, puis décroissant.
  5. Calculer la moyenne sans importer de module.
  6. Créer un tuple t à partir de la liste. Pourquoi utiliser un tuple plutôt qu'une liste ?
  7. Accéder au dernier élément avec un index négatif.
notes = [14, 8, 17, 12, 9, 15] notes.append(11) # [14,8,17,12,9,15,11] notes.insert(2, 10) # [14,8,10,17,12,9,15,11] notes.remove(8) # supprime le premier 8 notes.sort() # ordre croissant notes.sort(reverse=True) # ordre décroissant moyenne = sum(notes) / len(notes) t = tuple(notes) # tuple immuable notes[-1] # dernier élément
💡 À retenir — Listes vs Tuples ▾
  • Les listes sont mutables (modifiables). Les tuples sont immuables (plus rapides, protègent les données).
  • Méthodes clés de liste : append(), insert(), remove(), pop(), sort(), reverse(), index(), count().
  • Index négatifs : -1 = dernier, -2 = avant-dernier, etc.
  • sum() et len() fonctionnent sur les deux.

Dictionnaires
◆ Intermédiaire § 7.6.2 · 7.6.3

Créer un dictionnaire etudiant contenant : nom, prénom, âge, notes (liste). Puis :

  1. Accéder au nom via la clé.
  2. Ajouter une clé "filiere".
  3. Modifier l'âge.
  4. Supprimer la clé "age".
  5. Itérer sur les clés, puis sur les paires clé-valeur.
  6. Vérifier si la clé "notes" existe.
  7. Utiliser get() pour accéder à une clé inexistante sans erreur.
etudiant = { "nom" : "Dupont", "prenom" : "Alice", "age" : 20, "notes" : [14, 16, 12] } etudiant["nom"] # → "Dupont" etudiant["filiere"] = "Info" etudiant["age"] = 21 del etudiant["age"] for cle in etudiant.keys(): print(cle) for cle, val in etudiant.items(): print(cle, "→", val) "notes" in etudiant # → True etudiant.get("mention", "N/A") # → "N/A"
💡 À retenir — Dictionnaires ▾
  • Un dictionnaire est une collection de paires clé : valeur. Les clés sont uniques.
  • Méthodes clés : .keys(), .values(), .items(), .get(clé, défaut), .update(), .pop().
  • Préférer .get() à d[clé] pour éviter un KeyError si la clé n'existe pas.
  • Les valeurs peuvent être de n'importe quel type, y compris des listes ou d'autres dictionnaires.

Structures Conditionnelles
◆ Intermédiaire § 7.7

Écrire les programmes suivants :

  1. Un programme qui demande une note (0-20) et affiche : Excellent (≥16), Bien (≥14), Assez Bien (≥12), Passable (≥10), Insuffisant (<10).
  2. Vérifier si une année saisie est bissextile (divisible par 4, sauf si divisible par 100, sauf si divisible par 400).
  3. Déterminer le signe d'un nombre : positif, négatif ou nul. Écrire cela avec une expression ternaire.
# 1. Mention note = float(input("Note : ")) if note >= 16: print("Excellent") elif note >= 14: print("Bien") elif note >= 12: print("Assez Bien") elif note >= 10: print("Passable") else: print("Insuffisant") # 2. Année bissextile a = int(input("Année : ")) bis = (a % 4 == 0 and a % 100 != 0) or (a % 400 == 0) print("Bissextile" if bis else "Non bissextile") # 3. Expression ternaire n = int(input("Nombre : ")) signe = "positif" if n > 0 else ("négatif" if n < 0 else "nul") print(signe)
💡 À retenir — Conditions ▾
  • Structure : if … elif … else (pas de switch en Python < 3.10).
  • Expression ternaire : val_si_vrai if condition else val_si_faux.
  • Opérateurs logiques : and, or, not (pas && ni ||).
  • L'indentation définit les blocs en Python — erreur d'indentation = SyntaxError.

Structures de Boucle
◆ Intermédiaire § 7.8

Résoudre les problèmes suivants, d'abord avec while puis avec for quand c'est possible :

  1. Afficher les nombres pairs entre 1 et 20.
  2. Calculer la factorielle de n (saisie utilisateur).
  3. Afficher la table de multiplication de 7.
  4. Parcourir une liste de prénoms et afficher ceux qui commencent par 'A'.
  5. Trouver le plus grand élément d'une liste sans utiliser max().
  6. Utiliser enumerate() pour afficher l'index et la valeur d'une liste.
# 1. Nombres pairs for i in range(2, 21, 2): print(i) # 2. Factorielle n = int(input("n = ")) fact = 1 for i in range(1, n+1): fact *= i # 3. Table de 7 for i in range(1, 11): print(f"7 × {i} = {7*i}") # 4. Prénoms commençant par 'A' prenoms = ["Alice", "Bob", "Anna", "Clara"] for p in prenoms: if p.startswith("A"): print(p) # 5. Maximum sans max() lst = [3, 7, 1, 9, 4] maxi = lst[0] for x in lst: if x > maxi: maxi = x # 6. enumerate() for idx, val in enumerate(lst): print(f"[{idx}] = {val}")
💡 À retenir — Boucles ▾
  • for x in séquence = boucle pour chaque élément. Préférer for quand le nombre d'itérations est connu.
  • while condition = tant que la condition est vraie. Attention aux boucles infinies !
  • range(début, fin, pas) — fin est exclu.
  • break sort de la boucle, continue passe à l'itération suivante.
  • enumerate() retourne (index, valeur) — très utile pour éviter d'écrire range(len(...)).

Fonctions & Paramètres
▲ Avancé § 7.9

Écrire les fonctions suivantes :

  1. Une fonction est_premier(n) qui retourne True si n est premier.
  2. Une fonction statistiques(notes) qui retourne (min, max, moyenne) sous forme de tuple.
  3. Une fonction factorielle(n) récursive.
  4. Une fonction avec un paramètre par défaut : saluer(nom, politesse="Bonjour").
  5. Illustrer la différence entre variable locale et variable globale avec un exemple.
# 1. Premier def est_premier(n): if n < 2: return False for i in range(2, int(n**0.5)+1): if n % i == 0: return False return True # 2. Statistiques def statistiques(notes): return min(notes), max(notes), sum(notes)/len(notes) # 3. Récursion def factorielle(n): if n <= 1: return 1 return n * factorielle(n - 1) # 4. Paramètre par défaut def saluer(nom, politesse="Bonjour"): print(f"{politesse}, {nom} !") saluer("Alice") # Bonjour, Alice ! saluer("Bob", "Bonsoir") # Bonsoir, Bob ! # 5. Variable locale vs globale compteur = 0 # globale def incrementer(): global compteur compteur += 1 incrementer(); print(compteur) # → 1
💡 À retenir — Fonctions ▾
  • Définition : def nom(params): … return valeur.
  • Une fonction peut retourner plusieurs valeurs sous forme de tuple : return a, b, c.
  • Les paramètres avec valeur par défaut doivent être en fin de liste de paramètres.
  • Variable locale : ne vit que dans la fonction. Variable globale : déclarée hors fonction. Utiliser global pour la modifier dans une fonction.
  • La récursion nécessite impérativement un cas de base pour éviter la récursion infinie.

Compréhension de listes
▲ Avancé § 7.10

Réécrire chaque boucle sous forme de compréhension de liste :

  1. Créer la liste des carrés de 1 à 10.
  2. Filtrer les nombres impairs d'une liste.
  3. Créer une liste de tuples (i, i²) pour i de 1 à 5.
  4. Mettre tous les mots d'une phrase en majuscules.
  5. Créer un dictionnaire {n: n**2} pour n de 1 à 5 (compréhension de dictionnaire).
# 1. Carrés carres = [x**2 for x in range(1, 11)] # 2. Nombres impairs (filtre avec if) lst = [1,2,3,4,5,6] impairs = [x for x in lst if x % 2 != 0] # 3. Tuples (i, i²) pairs = [(i, i**2) for i in range(1, 6)] # 4. Mots en majuscules phrase = "bonjour le monde" mots = [m.upper() for m in phrase.split()] # 5. Compréhension de dictionnaire d = {n: n**2 for n in range(1, 6)} # → {1:1, 2:4, 3:9, 4:16, 5:25}
💡 À retenir — Compréhension de liste ▾
  • Syntaxe : [expression for var in itérable if condition].
  • Plus concis et souvent plus rapide qu'une boucle for classique.
  • Compréhension de dict : {clé: valeur for var in itérable}.
  • Compréhension de set : {expression for var in itérable}.
  • Ne pas abuser : si trop complexe, une boucle normale est plus lisible.

NumPy — Tableaux & Opérations
⊕ NumPy § 8.2

Importer NumPy et réaliser les opérations suivantes :

  1. Créer un tableau de 10 zéros, puis un tableau de 5 valeurs toutes égales à 7.
  2. Créer un tableau des entiers de 0 à 20 avec arange(), puis un tableau de 5 valeurs régulièrement espacées entre 0 et 1 avec linspace().
  3. Créer le tableau a = np.array([1, 4, 9, 16, 25]). Appliquer la racine carrée à tous les éléments sans boucle.
  4. Créer une matrice identité 3×3. Créer une matrice aléatoire 2×3.
  5. Effectuer la multiplication matricielle de deux matrices compatibles.
  6. Calculer la moyenne, le maximum et l'écart-type d'un tableau.
import numpy as np # 1. np.zeros(10) np.full(5, 7) # 2. np.arange(0, 21) # [0, 1, ..., 20] np.linspace(0, 1, 5) # [0., 0.25, 0.5, 0.75, 1.] # 3. Vectorisation a = np.array([1, 4, 9, 16, 25]) np.sqrt(a) # → [1., 2., 3., 4., 5.] # 4. Matrices np.eye(3) # identité 3×3 np.random.rand(2, 3) # aléatoire 2×3 # 5. Multiplication matricielle A = np.array([[1,2],[3,4]]) B = np.array([[5,6],[7,8]]) np.dot(A, B) # ou A @ B # 6. Statistiques t = np.array([10, 20, 30, 40]) t.mean(), t.max(), t.std()
💡 À retenir — NumPy ▾
  • NumPy opère sur des tableaux entiers sans boucle : c'est la vectorisation — beaucoup plus rapide.
  • arange(debut, fin, pas) génère des entiers ; linspace(début, fin, nb) génère des flottants régulièrement espacés.
  • Fonctions universelles (ufuncs) : np.sqrt, np.sin, np.exp, np.log — s'appliquent élément par élément.
  • Multiplication matricielle : np.dot(A, B) ou l'opérateur @. Ne pas confondre avec A * B (multiplication élément par élément).
  • Attributs utiles : .shape, .dtype, .ndim, .size.

▲ Avancé ⊕ NumPy Tous chapitres

Écrire un programme complet de gestion de notes d'une classe. Le programme doit :

  1. Stocker les données dans un dictionnaire : {"Alice": [14,16,12], "Bob": [9,11,8], "Clara": [18,17,19]}.
  2. Définir une fonction moyenne(notes) utilisant NumPy.
  3. Afficher pour chaque étudiant : son nom, sa moyenne (arrondie à 1 décimale) et sa mention.
  4. Trouver et afficher l'étudiant avec la meilleure moyenne.
  5. Utiliser une compréhension de liste pour obtenir la liste des étudiants ayant une moyenne ≥ 12.
  6. Calculer la moyenne générale de la classe avec NumPy.
import numpy as np classe = { "Alice": [14, 16, 12], "Bob": [9, 11, 8 ], "Clara": [18, 17, 19] } def moyenne(notes): return np.mean(notes) def mention(m): if m >= 16: return "Très Bien" elif m >= 14: return "Bien" elif m >= 12: return "Assez Bien" elif m >= 10: return "Passable" else: return "Insuffisant" # Affichage + recherche du meilleur meilleures = {} for nom, notes in classe.items(): m = moyenne(notes) meilleures[nom] = m print(f"{nom} : {m:.1f} — {mention(m)}") # Meilleur étudiant best = max(meilleures, key=lambda k: meilleures[k]) print(f"\nMeilleur : {best} avec {meilleures[best]:.1f}") # Admis (≥12) par compréhension admis = [n for n, m in meilleures.items() if m >= 12] print("Admis :", admis) # Moyenne générale toutes = np.concatenate(list(classe.values())) print(f"Moyenne classe : {np.mean(toutes):.2f}")
💡 À retenir — Synthèse & Bonnes pratiques ▾
  • Décomposer un problème complexe en fonctions courtes et réutilisables.
  • max(dict, key=lambda k: dict[k]) = trouver la clé ayant la valeur maximale.
  • np.concatenate() fusionne plusieurs tableaux en un seul.
  • Combiner dictionnaire + boucle + compréhension + NumPy = script Python professionnel.
  • Toujours tester ses fonctions avec des cas simples avant de les intégrer.
