💰 Calculateur de budget mensuel

✦ Facile input / dict / boucle
Contexte : Tu viens de commencer à vivre seul(e) et tu veux créer un outil simple pour suivre tes dépenses mensuelles et savoir s'il te reste de l'argent à la fin du mois.
// Missions
  1. Demander le salaire mensuel net de l'utilisateur.
  2. Demander les dépenses par catégorie (loyer, courses, transport, loisirs, autres) via input().
  3. Stocker chaque dépense dans un dictionnaire.
  4. Calculer et afficher le total des dépenses et le solde restant.
  5. Afficher un avertissement si le solde est négatif, un message d'encouragement sinon.
  6. Bonus : Afficher le pourcentage de chaque poste par rapport au salaire.
def budget_mensuel():
    print("=== Calculateur de Budget Mensuel ===")

    salaire = float(input("Salaire mensuel net (€) : "))

    categories = ["Loyer", "Courses", "Transport", "Loisirs", "Autres"]
    depenses = {}

    for cat in categories:
        montant = float(input(f"{cat} (€) : "))
        depenses[cat] = montant

    total  = sum(depenses.values())
    solde  = salaire - total

    print("\n--- Récapitulatif ---")
    for cat, m in depenses.items():
        pct = (m / salaire) * 100
        print(f"  {cat:<12} {m:>8.2f} €  ({pct:.1f}%)")

    print(f"\nTotal dépenses : {total:.2f} €")
    print(f"Solde restant  : {solde:.2f} €")

    if solde < 0:
        print("⚠️  Attention : tu dépenses plus que tu ne gagnes !")
    elif solde < salaire * 0.1:
        print("💡 Il reste peu — pense à mettre de côté !")
    else:
        print(f"✅ Bien ! Tu économises {solde:.2f} € ce mois.")

budget_mensuel()
Pense à tester avec un solde positif et un solde négatif pour valider les deux branches.
  • input() retourne une chaîne → toujours convertir avec float() ou int().
  • Boucler sur une liste de catégories pour remplir un dictionnaire : pattern très courant.
  • sum(dict.values()) = somme de toutes les valeurs du dictionnaire.
  • Formatage aligné : {valeur:>8.2f} = aligné à droite sur 8 chars, 2 décimales.

🎲 Jeu du nombre mystère

✦ Facile while / random / conditions
Contexte : Tu veux créer un mini-jeu pour t'amuser. L'ordinateur choisit un nombre secret entre 1 et 100, et le joueur doit le deviner avec des indices.
// Missions
  1. Générer un nombre aléatoire entre 1 et 100 avec random.randint().
  2. Boucler jusqu'à ce que le joueur trouve le nombre.
  3. À chaque tentative, indiquer si c'est trop grand, trop petit, ou trouvé.
  4. Compter le nombre d'essais et afficher un message selon le score (≤5 : excellent, ≤10 : bien, >10 : peut mieux faire).
  5. Bonus : Proposer de rejouer et afficher le record de la session.
import random

def jouer():
    secret  = random.randint(1, 100)
    essais  = 0
    trouve  = False

    print("🎲 J'ai choisi un nombre entre 1 et 100. À toi !")

    while not trouve:
        tentative = int(input("Ton nombre : "))
        essais += 1

        if   tentative < secret: print("📈 Trop petit !")
        elif tentative > secret: print("📉 Trop grand !")
        else:
            trouve = True
            print(f"🎉 Bravo ! Trouvé en {essais} essai(s) !")

    if   essais <= 5:  print("⭐ Excellent !")
    elif essais <= 10: print("👍 Bien joué !")
    else:              print("💪 Peut mieux faire...")

    return essais

# Bonus : session avec record
record = float("inf")
while True:
    score  = jouer()
    record = min(record, score)
    print(f"🏆 Record session : {record} essai(s)")
    if input("Rejouer ? (o/n) : ").lower() != "o":
        break
  • import random — random.randint(a, b) inclut les deux bornes.
  • Le flag booléen (trouve = False) est un pattern classique pour contrôler une boucle while.
  • float("inf") = l'infini positif, pratique pour initialiser un minimum.
  • str.lower() permet de rendre la saisie insensible à la casse.

📚 Bulletin de notes automatique

◆ Moyen dict / fonctions / NumPy
Contexte : Tu es délégué(e) de classe. Le professeur t'a donné la liste des notes de 5 matières pour 4 étudiants. Il te demande de générer automatiquement les bulletins.
// Données de départ
classe = {
    "Alice":   {"Maths":15, "Physique":13, "Info":18, "Anglais":12, "Français":14},
    "Bob":     {"Maths": 9, "Physique": 7, "Info":11, "Anglais":14, "Français": 8},
    "Clara":   {"Maths":17, "Physique":16, "Info":14, "Anglais":19, "Français":15},
    "Damien":  {"Maths":10, "Physique":12, "Info": 9, "Anglais": 7, "Français":11}
}
// Missions
  1. Écrire une fonction calcul_bulletin(nom, notes_dict) qui affiche toutes les notes et la moyenne avec NumPy.
  2. Afficher le classement de la classe du meilleur au moins bon.
  3. Identifier la matière la plus forte et la plus faible de chaque étudiant.
  4. Calculer la moyenne de classe par matière avec NumPy.
  5. Bonus : Repérer les étudiants en dessous de la moyenne de classe.
import numpy as np

classe = {
    "Alice" : {"Maths":15,"Physique":13,"Info":18,"Anglais":12,"Français":14},
    "Bob"   : {"Maths": 9,"Physique": 7,"Info":11,"Anglais":14,"Français": 8},
    "Clara" : {"Maths":17,"Physique":16,"Info":14,"Anglais":19,"Français":15},
    "Damien": {"Maths":10,"Physique":12,"Info": 9,"Anglais": 7,"Français":11},
}

def calcul_bulletin(nom, notes):
    vals    = np.array(list(notes.values()))
    moyenne = np.mean(vals)
    matieres= list(notes.keys())
    forte   = matieres[np.argmax(vals)]
    faible  = matieres[np.argmin(vals)]
    print(f"\n{'='*35}")
    print(f"  BULLETIN — {nom}")
    print(f"{'='*35}")
    for mat, n in notes.items():
        print(f"  {mat:<12} {n:>4}/20")
    print(f"  {'Moyenne':<12} {moyenne:>5.2f}/20")
    print(f"  ✅ Point fort  : {forte}")
    print(f"  ⚠️  Point faible : {faible}")
    return moyenne

# Génération des bulletins + classement
moyennes = {}
for nom, notes in classe.items():
    moyennes[nom] = calcul_bulletin(nom, notes)

# Classement
classement = sorted(moyennes.items(), key=lambda x: x[1], reverse=True)
print("\n🏆 Classement :")
for rang, (nom, moy) in enumerate(classement, 1):
    print(f"  {rang}. {nom:<10} {moy:.2f}/20")

# Moyenne par matière (NumPy)
matieres = list(next(iter(classe.values())).keys())
matrice  = np.array([[v for v in n.values()] for n in classe.values()])
print("\n📊 Moyennes par matière :")
for mat, moy in zip(matieres, matrice.mean(axis=0)):
    print(f"  {mat:<12} {moy:.2f}/20")
  • np.argmax() / np.argmin() retournent l'index du max/min — très utile pour retrouver la matière correspondante.
  • sorted(items, key=lambda x: x[1], reverse=True) = trier un dictionnaire par valeur.
  • matrice.mean(axis=0) = moyenne par colonne (par matière) ; axis=1 = par ligne (par étudiant).
  • zip(liste1, liste2) = itérer sur deux listes en parallèle.

🔐 Générateur et vérificateur de mots de passe

◆ Moyen str / fonctions / random
Contexte : Tu développes un outil de sécurité pour aider les utilisateurs à créer des mots de passe forts et vérifier si leurs mots de passe existants sont sécurisés.
// Missions
  1. Écrire verifier_mdp(mdp) qui vérifie : longueur ≥ 8, au moins 1 majuscule, 1 minuscule, 1 chiffre, 1 caractère spécial. Retourner un score de 0 à 5 et un niveau ("Très faible" à "Fort").
  2. Écrire generer_mdp(longueur=12) qui génère un mot de passe aléatoire fort.
  3. Afficher le résultat sous forme de rapport lisible.
import random
import string

def verifier_mdp(mdp):
    criteres = {
        "Longueur ≥ 8"       : len(mdp) >= 8,
        "Majuscule"          : any(c.isupper() for c in mdp),
        "Minuscule"          : any(c.islower() for c in mdp),
        "Chiffre"            : any(c.isdigit() for c in mdp),
        "Caractère spécial"  : any(c in string.punctuation for c in mdp),
    }
    score  = sum(criteres.values())
    niveaux= ["Très faible", "Faible", "Moyen", "Bon", "Très bon", "Fort"]

    print(f"\n🔐 Analyse de '{mdp}'")
    for crit, ok in criteres.items():
        print(f"  {'✅' if ok else '❌'}  {crit}")
    print(f"\n  Score  : {score}/5 — {niveaux[score]}")
    return score

def generer_mdp(longueur=12):
    chars = (string.ascii_letters + string.digits + "@#$%!&*")
    # Garantir au moins un de chaque type
    mdp = [
        random.choice(string.ascii_uppercase),
        random.choice(string.ascii_lowercase),
        random.choice(string.digits),
        random.choice("@#$%!&*"),
    ]
    mdp += [random.choice(chars) for _ in range(longueur - 4)]
    random.shuffle(mdp)
    return "".join(mdp)

# Test
verifier_mdp("bonjour")
verifier_mdp("Python3#!")
nouveau = generer_mdp()
print(f"\n✨ Mot de passe généré : {nouveau}")
verifier_mdp(nouveau)
  • any(condition for x in iterable) = vrai si au moins un élément satisfait la condition.
  • str.isupper(), str.islower(), str.isdigit() = méthodes de classification des caractères.
  • string.ascii_letters, string.digits, string.punctuation = constantes du module string.
  • "".join(liste) = assembler une liste de caractères en chaîne.
  • random.shuffle(liste) = mélange en place (modifie la liste).

🛒 Caisse enregistreuse simplifiée

◆ Moyen dict / boucles / fonctions
Contexte : Tu travailles dans une petite boutique. Le gérant te demande de créer un programme de caisse simple pour calculer les totaux, appliquer des remises et afficher un ticket de caisse.
// Catalogue produits
catalogue = {
    "pomme"   : 0.80,
    "pain"    : 1.20,
    "lait"    : 0.95,
    "fromage" : 3.50,
    "yaourt"  : 2.10,
}
// Missions
  1. Permettre à l'utilisateur d'ajouter des articles à son panier (nom + quantité) jusqu'à saisir "fin". Gérer les articles inconnus.
  2. Calculer le sous-total, appliquer une remise de 10% si total > 20€.
  3. Afficher un ticket de caisse formaté avec article, quantité, prix unitaire et total ligne.
  4. Bonus : Calculer la TVA à 5,5% et afficher le total TTC.
catalogue = {
    "pomme":0.80, "pain":1.20, "lait":0.95,
    "fromage":3.50, "yaourt":2.10
}

def saisir_panier():
    panier = {}
    print("Articles disponibles :", ", ".join(catalogue.keys()))
    while True:
        article = input("Article (ou 'fin') : ").lower()
        if article == "fin": break
        if article not in catalogue:
            print("❌ Article inconnu."); continue
        qte = int(input(f"Quantité de {article} : "))
        panier[article] = panier.get(article, 0) + qte
    return panier

def ticket(panier):
    print("\n" + "="*42)
    print("        🧾 TICKET DE CAISSE")
    print("="*42)
    print(f"{'Article':<12} {'Qté':>4} {'P.U.':>7} {'Total':>8}")
    print("-"*42)
    sous_total = 0
    for art, qte in panier.items():
        pu    = catalogue[art]
        ligne = pu * qte
        sous_total += ligne
        print(f"{art:<12} {qte:>4} {pu:>7.2f}€ {ligne:>8.2f}€")
    print("="*42)

    remise = sous_total * 0.10 if sous_total > 20 else 0
    net    = sous_total - remise
    tva    = net * 0.055
    ttc    = net + tva

    if remise > 0:
        print(f"{'Sous-total':<22} {sous_total:>8.2f}€")
        print(f"{'Remise 10%':<22} {-remise:>8.2f}€")
    print(f"{'Net HT':<22} {net:>8.2f}€")
    print(f"{'TVA 5.5%':<22} {tva:>8.2f}€")
    print(f"{'TOTAL TTC':<22} {ttc:>8.2f}€")
    print("="*42)

panier = saisir_panier()
if panier:
    ticket(panier)
else:
    print("Panier vide.")
  • dict.get(clé, valeur_défaut) = récupérer sans erreur, et initialiser à 0 si absent.
  • continue dans une boucle = sauter directement à l'itération suivante.
  • Formatage de tableau : {texte:<12} (aligné gauche), {nombre:>8.2f} (aligné droite, 2 déc.).
  • Séparer la saisie de l'affichage en deux fonctions = bonne pratique.

📊 Analyse de données de ventes avec NumPy

▲ Difficile NumPy / matrices / stats
Contexte : Tu es analyste junior dans une entreprise. On te donne les ventes mensuelles de 4 produits sur 6 mois. Tu dois produire un rapport statistique complet.
// Données (lignes = produits, colonnes = mois Jan→Juin)
import numpy as np
ventes = np.array([
    [120, 135, 148, 162, 175, 190],  # Produit A
    [ 85,  92,  78,  95,  88,  102],  # Produit B
    [200, 215, 198, 220, 235, 248],  # Produit C
    [ 45,  52,  61,  49,  70,  75],  # Produit D
])
// Missions
  1. Calculer le total des ventes par produit et par mois avec sum(axis=...).
  2. Identifier le mois le plus performant et le produit le plus vendu.
  3. Calculer la croissance mensuelle en % pour chaque produit (utiliser le slicing NumPy).
  4. Normaliser les données entre 0 et 1 avec NumPy (min-max scaling).
  5. Afficher un rapport complet et lisible.
import numpy as np

ventes = np.array([
    [120,135,148,162,175,190],
    [ 85, 92, 78, 95, 88,102],
    [200,215,198,220,235,248],
    [ 45, 52, 61, 49, 70, 75],
])

produits = ["Produit A", "Produit B", "Produit C", "Produit D"]
mois     = ["Jan","Fév","Mar","Avr","Mai","Jun"]

# 1. Totaux
total_par_produit = ventes.sum(axis=1)   # somme par ligne
total_par_mois    = ventes.sum(axis=0)   # somme par colonne

print("📦 Total par produit :")
for p, t in zip(produits, total_par_produit):
    print(f"  {p} : {t} unités")

# 2. Meilleur mois et meilleur produit
meilleur_mois    = mois[np.argmax(total_par_mois)]
meilleur_produit = produits[np.argmax(total_par_produit)]
print(f"\n🏆 Meilleur mois    : {meilleur_mois}")
print(f"🥇 Meilleur produit : {meilleur_produit}")

# 3. Croissance mensuelle (%)
#    diff entre mois[i+1] et mois[i], divisé par mois[i]
croissance = ((ventes[:, 1:] - ventes[:, :-1]) / ventes[:, :-1]) * 100
print("\n📈 Croissance mensuelle (%) :")
for p, ligne in zip(produits, croissance):
    vals = "  ".join([f"{v:+.1f}%" for v in ligne])
    print(f"  {p}: {vals}")

# 4. Normalisation min-max
v_min  = ventes.min()
v_max  = ventes.max()
normal = (ventes - v_min) / (v_max - v_min)
print("\n📐 Données normalisées (extrait) :")
print(np.round(normal, 2))
  • axis=0 = opération sur les colonnes (vertical), axis=1 = sur les lignes (horizontal).
  • Slicing 2D : A[:, 1:] = toutes les lignes, colonnes à partir de la 2e.
  • La vectorisation NumPy permet d'éviter totalement les boucles sur des matrices.
  • Normalisation min-max : (x - min) / (max - min) — ramène toutes les valeurs entre 0 et 1.

🔢 Chiffrement César

◆ Moyen str / fonctions / ord / chr
Contexte : Tu veux encoder des messages secrets à envoyer à tes amis. Le chiffrement César consiste à décaler chaque lettre de l'alphabet d'un nombre fixe de positions.
// Missions
  1. Écrire chiffrer(texte, decalage) qui chiffre un texte (garder les espaces et ponctuations inchangés, gérer majuscules et minuscules).
  2. Écrire dechiffrer(texte, decalage) en réutilisant chiffrer.
  3. Bonus : Écrire casser_cesar(texte) qui essaie tous les décalages et affiche les 26 possibilités.
def chiffrer(texte, decalage):
    resultat = ""
    for c in texte:
        if c.isalpha():
            base = ord('A') if c.isupper() else ord('a')
            resultat += chr((ord(c) - base + decalage) % 26 + base)
        else:
            resultat += c   # espaces, ponctuation inchangés
    return resultat

def dechiffrer(texte, decalage):
    return chiffrer(texte, -decalage)

def casser_cesar(texte):
    print("🔓 Toutes les possibilités :")
    for d in range(26):
        print(f"  Décalage {d:>2} : {chiffrer(texte, d)}")

# Test
msg     = "Bonjour Python !"
chiffre = chiffrer(msg, 3)
print(f"Chiffré : {chiffre}")
print(f"Déchiffré : {dechiffrer(chiffre, 3)}")
casser_cesar(chiffre)
  • ord(c) = code ASCII d'un caractère ; chr(n) = caractère depuis un code ASCII.
  • Le % 26 assure le bouclage dans l'alphabet (Z → A).
  • Déchiffrer = chiffrer avec le décalage opposé : éviter la duplication de code.
  • Principe de réutilisation : une bonne fonction peut être appelée par d'autres fonctions.

📅 Calendrier et gestion du temps

◆ Moyen conditions / boucles / fonctions
Contexte : Tu dois créer un outil qui aide à planifier des événements en calculant des informations sur les dates et les jours.
// Missions
  1. Écrire est_bissextile(annee).
  2. Écrire jours_dans_mois(mois, annee) qui retourne le nombre de jours du mois.
  3. Écrire jours_restants_annee(jour, mois, annee) qui calcule les jours restants dans l'année.
  4. Bonus : Afficher un mini-calendrier textuel d'un mois donné (supposer que le 1er janvier est un lundi).
def est_bissextile(a):
    return (a % 4 == 0 and a % 100 != 0) or (a % 400 == 0)

def jours_dans_mois(mois, annee):
    jours = [0,31,28,31,30,31,30,31,31,30,31,30,31]
    if mois == 2 and est_bissextile(annee):
        return 29
    return jours[mois]

def jours_restants_annee(jour, mois, annee):
    total = sum(jours_dans_mois(m, annee) for m in range(mois+1, 13))
    total += jours_dans_mois(mois, annee) - jour
    return total

# Bonus : mini calendrier (en supposant que le 1er janv est Lun)
def calendrier(mois, annee, premier_jour=0):
    noms  = ["","Janvier","Février","Mars","Avril",
              "Mai","Juin","Juillet","Août","Sept.","Oct.","Nov.","Déc."]
    print(f"\n  {noms[mois]} {annee}")
    print("  Lu Ma Me Je Ve Sa Di")
    ligne = "     " * premier_jour
    for j in range(1, jours_dans_mois(mois, annee) + 1):
        ligne += f"{j:>3} "
        if (premier_jour + j) % 7 == 0:
            print(" " + ligne); ligne = ""
    if ligne.strip(): print(" " + ligne)

# Tests
print(est_bissextile(2024))                        # True
print(jours_dans_mois(2, 2024))                   # 29
print(jours_restants_annee(15, 6, 2025), "jours") # 199
calendrier(1, 2025, 2)                             # Mercredi 1er jan 2025

  • sum(f(x) for x in range(...)) = somme avec une expression génératrice.
  • Listes indexées à partir de 1 : mettre un 0 en position 0 pour aligner les indices sur les numéros de mois.

🧬 Simulation de population bactérienne

▲ Difficile NumPy / linspace / simulation
Contexte : En TP de biologie, tu modélises la croissance d'une population de bactéries selon le modèle logistique : la population croît rapidement au début puis ralentit quand elle atteint la capacité maximale du milieu.
// Missions
  1. Implémenter la formule : N(t) = K / (1 + ((K - N0) / N0) * exp(-r*t)) avec K=1000 (capacité max), N0=10 (population initiale), r=0.5 (taux de croissance).
  2. Créer un tableau de temps avec np.linspace(0, 20, 100).
  3. Calculer la population à chaque instant avec NumPy (sans boucle).
  4. Afficher les valeurs à t=0, 5, 10, 15, 20 sous forme de tableau.
  5. Trouver le moment où la population dépasse 500 (la moitié de K).
import numpy as np

# Paramètres
K  = 1000     # Capacité maximale
N0 = 10       # Population initiale
r  = 0.5      # Taux de croissance

# Temps : 100 points entre 0 et 20
t = np.linspace(0, 20, 100)

# Modèle logistique — vectorisé
N = K / (1 + ((K - N0) / N0) * np.exp(-r * t))

# Affichage à des instants clés
print(f"{'Temps':>6}  {'Population':>12}")
print("-"*22)
for temps in [0, 5, 10, 15, 20]:
    # Trouver l'index le plus proche du temps souhaité
    idx = np.argmin(np.abs(t - temps))
    print(f"{temps:>6}  {N[idx]:>12.2f}")

# Trouver quand N > 500
idx_500 = np.argmax(N > 500)  # argmax retourne le 1er True
print(f"\n⏱️  Population > 500 à t ≈ {t[idx_500]:.2f} heures")
print(f"   Valeur : {N[idx_500]:.2f} bactéries")

# Statistiques NumPy
print(f"\n📊 Croissance moyenne : {np.diff(N).mean():.4f} bact/pas")
print(f"   Taux de croissance max à : t ≈ {t[np.argmax(np.diff(N))]:.1f}")
  • np.exp(), np.log(), np.abs() = fonctions mathématiques vectorisées.
  • np.argmax(condition) sur un tableau booléen = index du premier True.
  • np.diff(N) = différences successives : [N[1]-N[0], N[2]-N[1], ...].
  • np.linspace est préféré à arange quand on veut un nombre précis de points entre deux valeurs.

🏦 Simulateur d'emprunt bancaire

▲ Difficile NumPy / fonctions / tableaux
Contexte : Tu veux emprunter de l'argent pour acheter une voiture. Tu développes un simulateur qui calcule tes mensualités, le total des intérêts payés et génère un tableau d'amortissement.
// Missions
  1. Calculer la mensualité avec la formule : M = C × (t/12) / (1 - (1 + t/12)^(-n)) où C = capital, t = taux annuel, n = durée en mois.
  2. Générer le tableau d'amortissement mois par mois (capital restant, intérêts, remboursement capital).
  3. Utiliser NumPy pour calculer les totaux sans boucle là où c'est possible.
  4. Afficher un résumé : coût total, total intérêts, mensualité.
  5. Bonus : Comparer 3 durées de prêt (3, 5, 7 ans) et afficher laquelle coûte le moins cher.
import numpy as np

def simuler_pret(capital, taux_annuel, duree_ans, afficher_tableau=True):
    t = taux_annuel / 12    # taux mensuel
    n = duree_ans * 12     # nb mois

    # Mensualité
    M = capital * t / (1 - (1 + t) ** (-n))

    if afficher_tableau:
        print(f"\n{'='*62}")
        print(f"  Prêt : {capital}€  |  Taux : {taux_annuel*100:.1f}%  |  Durée : {duree_ans} ans")
        print(f"  Mensualité : {M:.2f}€")
        print(f"{'='*62}")
        print(f"{'Mois':>5} {'Cap.Restant':>12} {'Intérêts':>10} {'Remb.Cap.':>10}")
        print("-"*62)

    solde      = capital
    interets_t = 0

    for mois in range(1, n + 1):
        interets = solde * t
        remb_cap = M - interets
        solde   -= remb_cap
        interets_t += interets
        if afficher_tableau and mois % 12 == 0:  # afficher 1 ligne / an
            print(f"{mois:>5} {max(solde,0):>12.2f}€ {interets:>9.2f}€ {remb_cap:>9.2f}€")

    total = M * n
    if afficher_tableau:
        print(f"\n  Total remboursé : {total:.2f}€")
        print(f"  Total intérêts  : {interets_t:.2f}€")

    return total, interets_t, M

# Simulation principale
simuler_pret(15000, 0.045, 5)

# Bonus : comparaison des durées
print("\n🔍 Comparaison des durées :")
print(f"{'Durée':>8} {'Mensualité':>12} {'Coût total':>12} {'Intérêts':>12}")
print("-"*48)
resultats = {}
for ans in [3, 5, 7]:
    total, inter, mens = simuler_pret(15000, 0.045, ans, afficher_tableau=False)
    resultats[ans] = total
    print(f"{ans:>5} ans  {mens:>10.2f}€ {total:>10.2f}€ {inter:>10.2f}€")

meilleur = min(resultats, key=lambda k: resultats[k])
print(f"\n✅ Moins cher : {meilleur} ans ({resultats[meilleur]:.2f}€ au total)")
  • Les fonctions peuvent avoir des paramètres booléens (afficher_tableau=True) pour contrôler leur comportement.
  • min(dict, key=lambda k: dict[k]) = trouver la clé avec la valeur minimale.
  • Une même fonction peut être appelée avec des paramètres différents pour comparer des scénarios.
  • Afficher une ligne sur N (if mois % 12 == 0) pour des tableaux lisibles.
